# Flutter Trading Expense Tracker

A mobile-first Flutter app for quickly tracking day-to-day trading business expenses.

## Implemented highlights

- Mandatory fixed dropdown of 26 expense categories.
- Fast 3-step entry flow: category, amount, optional note.
- Auto-save with current date-time (editable date).
- Payment mode support: cash / bank / UPI / credit.
- Local SQLite storage.
- Dashboard metrics: today, month, year, financial year (Apr-Mar).
- Analytics:
  - Monthly comparison bar chart.
  - Category-wise pie chart.
  - Highest spending category highlight.
  - Top 3 categories.
- Expense list with date/category filtering.
- Excel export for daily, monthly, and financial year reports.

## Run

```bash
flutter pub get
flutter run
```
